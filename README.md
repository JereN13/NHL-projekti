# Näyttö 1 työssäopista.

Projektina oli tehdä statistiikka sivu johon voi lisätä pelaajia, tiimejä, ja statistiikkaa pelaajille, playoff kaava sivu, aikataulu sivu, ja lopuksi live versio statistiikka sivusta joka on koko ajan aktiivinen. Projektiin kului neljä päivää yhteensä tehdessä kaikki sivut ja sitä käytettiin NHL turnausta varten joka pidettiin pitkänä perjantaina täällä Remakella.
